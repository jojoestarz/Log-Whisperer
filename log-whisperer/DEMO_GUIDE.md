# 🎬 Log Whisperer - Complete Demo Guide

## 🚀 Quick Start

### 1. Start the System
```bash
# Terminal 1 - Backend
cd log-whisperer
../.venv/bin/uvicorn server:app --reload --port 8000

# Terminal 2 - Frontend
cd log-whisperer/ui
npm run dev
```

### 2. Open Browser
Navigate to: `http://localhost:5173`

### 3. Run Demo
Click **"INJECT INCIDENT"** and watch the magic happen!

**Writer Agent generates remediation plan**

- Targets specific services
