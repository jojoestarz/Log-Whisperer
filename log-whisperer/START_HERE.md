## 🐛 Troubleshooting

**Backend error?**
```bash
cd log-whisperer
pip install -r requirements.txt
python server.py
```

**Frontend error?**
```bash
cd log-whisperer/ui
npm install
npm run dev
```

**Simulation not working?**
- Check browser console (F12)
- Verify SSE connection in Network tab
- Restart both servers
